# 岱宗盒子 iOS 首版

原生 SwiftUI 客户端工程，最低支持 iOS 17。用 Xcode 打开 `XJTUToolbox.xcodeproj` 即可查看工程。

## 当前范围

- 首页概览与常用服务入口
- 周课表浏览
- 成绩列表与加权 GPA 演示计算
- 校园卡余额和消费流水页面
- 图书馆座位选择交互
- 空闲教室筛选
- 校园通知列表、个人页和关于页
- 社区功能暂不实现

目前数据均为本地演示内容。CAS 登录/MFA、教务和校园系统接口尚未接入，因此不要将演示余额、成绩、座位和通知当作实时信息。接口接入时建议沿用独立的数据源协议，让 SwiftUI 界面可以切换真实校园数据与预览数据。
